# MonitorIA — Downloads oficiais

Este é o repositório **público de distribuição** do [MonitorIA](https://monitoria.cam), mantido pela BigCorps. Ele hospeda exclusivamente pacotes oficiais de instalação para Windows 24/7 e Linux, além de arquivos de integridade e verificação.

**Acesse [Releases](https://github.com/BigCorps/MonitorIA-Downloads/releases) para obter as versões publicadas.**

## Plataformas

- **Windows 10/11 (64 bits):** `MonitorIA-Setup.exe`, edição 24/7 para computadores dedicados.
- **Linux x64:** `monitoria-agent-linux-x64.tar.gz`.
- **Linux ARM64:** `monitoria-agent-linux-arm64.tar.gz`.

Cada release acompanha arquivos de SHA-256 e assinatura de integridade para conferência do pacote baixado. A versão para Microsoft Store é distribuída separadamente.

Para iniciar a instalação com orientações, utilize [monitoria.cam/instalar](https://monitoria.cam/instalar).

## Segurança e privacidade

Este repositório **não contém o código-fonte privado**, arquivos de configuração de clientes, chaves, certificados privados ou credenciais do Agent. Não execute pacotes sem conferir que foram publicados em uma release oficial.
